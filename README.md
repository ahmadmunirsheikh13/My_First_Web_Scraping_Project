# Web Scraping Project – Laptop Products

## Overview
This project scrapes product information (title, price, description, and rating) from the test e-commerce site [webscraper.io](https://webscraper.io/test-sites/e-commerce/static/computers/laptops).  
The data is collected across multiple pages and saved into a CSV file (`products.csv`).

---

## Features
 Scrapes product details from 20 pages of laptops.
 Extracts:
   **Title**
   **Price**
   **Description**
   **Rating**
 Saves results into a structured CSV file for easy analysis.

---

## Requirements
Install the following Python libraries before running the script:

pip install requests beautifulsoup4
